# Auto Region 161 — установка и настройка ГБО, Ростов-на-Дону

Одностраничный сайт. Чистая статика: HTML + CSS + JS, без сборки и без npm.

Правится в двух файлах:
- `content.js` — все тексты по блокам
- `config.js` — телефон, ссылки, график работы, константы калькулятора

Фото — в `img/`. Открывается локально: `python3 -m http.server` в этой папке.
